# Keziah Dorothy A G — Interactive Portfolio

A responsive, glassmorphic portfolio built with plain HTML, CSS and JavaScript.

## Included
- Glassmorphic responsive UI
- Animated background orbs
- Dark/light mode with localStorage persistence
- Mobile navigation
- Scroll reveal animations
- 3D hover effect on the hero visual
- Filterable project cards
- LinkedIn CTA
- Responsive layout

## Add your real profile image
Create an `assets` folder and place your photo at:

`assets/profile.jpg`

Then replace the `.profile-placeholder` block in `index.html` with:

`<img src="assets/profile.jpg" alt="Keziah Dorothy A G">`

## Important
The LinkedIn URL was supplied, but this environment cannot directly fetch LinkedIn profile contents. The page therefore uses information already available from the project/context history and keeps the profile-photo area as a safe placeholder rather than inventing LinkedIn facts.
